# Security Policy

## Supported versions

Security fixes are evaluated for the current `main` branch. Older commits, forks, and deployments are not guaranteed to receive updates.

## Reporting a vulnerability

Please **do not open a public issue or pull request** containing exploit details, credentials, or sensitive data. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature for this repository when available. If it is not enabled, contact the organization maintainers through an established private channel and request a secure reporting method before sharing details.

Include affected versions, reproduction steps, potential impact, and a suggested mitigation if known. Do not test against production users or access data without authorization. Maintainers will triage reports as capacity allows; no fixed response or remediation SLA is promised.

## Scope

This repository contains the frontend. Backend API issues should also be reported privately to the maintainers of [3DMeta-Shop-Object-3D](https://github.com/iranpsc/3DMeta-Shop-Object-3D).
